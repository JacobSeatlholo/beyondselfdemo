# Beyond Self NPO — Demo Website

**Empowering Communities. Transforming Lives.**

The official demo website for **Beyond Self**, a registered non-profit organisation
(Reg. No. **K2025443565**) based in Vosloorus, Gauteng, South Africa.

Beyond Self is a voluntary, non-profit, non-partisan organisation building a grassroots
network of socially conscious citizens — people who contribute their **time, ideas and
resources** to address South Africa's social, economic and environmental challenges.

---

## ✨ Highlights

- **Hero & trust-first design** — registration number, location and contact visible from the first scroll
- **Our Story** — the journey from neighbours to a registered NPO
- **Vision & Mission** — straight from the organisation's constitution (Clauses 3 & 4)
- **What We Do** — shelter & home builds, learner support, community gift drives, active citizenship
- **Featured Campaign: HOME BUILD** — raising **R15 000** to extend a home for a family of four,
  with a live build-milestone tracker and one-tap copy EFT details (Standard Bank · Acc 10254826774 · Ref HOME BUILD)
- **Build Journey** — real site footage: *Phase 1 · Foundations* and *Phase 2 · Walls Rising*
- **Impact gallery, values, leadership & governance** sections that put donor trust first
- **Get Involved** — give, volunteer (open to 18+, per Clause 6.1) or partner
- **Contact** — address, phone/WhatsApp (078 398 5023), Google Maps directions and a demo message form
- Footer credit: **Demo built by Business Hustle**

## 🛠 Tech Stack

| Layer     | Choice                                          |
| --------- | ----------------------------------------------- |
| Framework | Next.js 16 (App Router) + TypeScript            |
| Styling   | Tailwind CSS 4 + shadcn/ui                      |
| Fonts     | Fraunces (display) + Inter (body), self-hosted  |
| Motion    | Framer Motion                                   |
| Icons     | Lucide                                          |
| Toasts    | Sonner                                          |

## 🚀 Getting Started

```bash
bun install
bun run dev        # start dev server on :3000
bun run lint       # eslint
```

## 📁 Structure

```
src/
├── app/                # layout, global styles, single-page route
├── components/
│   ├── ui/             # shadcn/ui primitives
│   └── site/           # page sections (hero, campaign, story, …)
public/
└── media/              # photos, videos, posters, logo & campaign poster
```
